### 2.1 用户角色设计

| 角色 | 说明 |
|------|------|
| 游客 | 未登录浏览商品 |
| 普通用户 | 购物车、下单、支付、查看订单 |
| 商家 | 商品管理、库存维护、处理订单 |
| 管理员 | 用户/商品/订单管理、运营数据看板 |

### 2.2 功能模块设计

用户服务、商品服务、购物车服务、订单服务、支付服务、库存服务、网关与治理、管理后台 8 大模块，覆盖电商核心链路。

### 2.3 核心业务流程

浏览商品 → 注册/登录 → 加入购物车 → 提交订单（锁定库存）→ 在线支付 → 支付成功扣减库存 / 失败释放库存 → 商家发货 → 确认收货 → 交易完成。

### 2.4 演进方向

阶段一（单体应用跑通闭环）→ 阶段二（按业务边界拆分为微服务）→ 阶段三（网关、配置中心、链路追踪等治理设施）→ 阶段四（Docker + Compose 容器化部署）。
