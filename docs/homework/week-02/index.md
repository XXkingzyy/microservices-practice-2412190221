## 二、功能规划

本周确定了课程项目主题：**订餐系统**，核心只保留用户、菜单、订单三个业务模块，并在根目录 `README.md` 中完成项目功能、用户角色、业务流程与演进方向的描述。

### 2.1 用户角色设计

| 角色 | 说明 |
|------|------|
| 顾客 | 注册登录、浏览菜单、下单、查看自己的订单 |
| 商家 | 维护菜单菜品、查看订单、接单/完成订单 |

### 2.2 功能模块设计

用户模块（注册/登录/用户信息）、菜单模块（菜品列表/详情/商家维护）、订单模块（创建订单/订单列表/状态更新）三个核心模块。

### 2.3 核心业务流程

顾客注册/登录 → 浏览菜单 → 下单 → 商家接单 → 商家完成订单 → 顾客查看订单。

### 2.4 演进方向

阶段一（单体应用跑通闭环）→ 阶段二（拆分为用户/菜单/订单三个微服务）→ 阶段三（Docker 容器化部署）。
